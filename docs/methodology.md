# 排名方法論

> **僅供研究與學習，不構成投資建議。** 本文件描述每日 Top 50 如何產生；排名不是報酬預測，
> 也不應被解讀為「有效」。回測（[backtest.md](backtest.md)）用同一套程式檢驗它，並揭露偏誤。

設計取捨見 [ADR 0003](adr/0003-features-and-regime.md)（因子與 regime）與
[ADR 0004](adr/0004-ranking-engine.md)（排名引擎）。程式在 `src/qrd/scoring/`，
預設參數集中在 `src/qrd/scoring/config.py`。

## 0. 流程總覽

```
qrd ingest  →  qrd features  →  qrd rank
價量／宏觀      因子、regime       Universe 過濾 → 標準化 → regime 加權 → 風險懲罰
                                  → 約束下貪婪選取 Top 50 → 分數分解、入選理由、主要風險
```

每個交易日 t 收盤後執行，只用 t 日（含）以前**可得**的資料，排名供 t+1 參考。

## 1. 時間對齊與 look-ahead

- 因子：t 日的值只用 t 日（含）以前的 K 棒（trailing 視窗）。
- 宏觀與 regime：只用 `available_date <= t` 的觀測（發布日，而非觀測日）。
- 排名：使用 t 日的因子快照、t 日的 regime、`date <= t` 的價格（流動性篩選與相關性）。
- 測試：`tests/test_lookahead.py`（特徵）與 `tests/test_rank_lookahead.py`（排名）。
  在多個切點 t，「只用 t 時可得資料重算」與「用完整歷史計算」的分數表、Top N、略過清單與 JSON
  必須**完全相同**；把 t 之後的資料竄改成亂數也不得改變結果；金絲雀測試證明用了未來因子會被偵測到。

## 2. Universe 過濾（每日）

以下任一不符者不參與排名，原因寫進輸出的 `ineligible`：

| 條件 | 預設 |
|---|---|
| t 日沒有 K 棒（過期資料） | 排除 |
| 最近 60 日平均成交額 | ≥ $5M |
| 最近收盤價 | ≥ $5 |
| 上市（可得）天數 | ≥ 60 個交易日 |
| 資料品質報告為 `error` | 排除（features 階段） |
| 因子覆蓋率（見 §4） | ≥ 0.6 |

歷史不足一年（`short_history`）的標的**可以**進榜，但會被扣分並標註「歷史不足，信心低」（PLAN §5）。

## 3. 因子與標準化

| 群組 | 因子（方向） | 轉換 |
|---|---|---|
| 動能 `momentum` | `mom_12_1`、`mom_6m`、`mom_3m`、`trend_200`（高 = 好） | — |
| 低風險 `low_risk` | `vol_63`、`downside_63`（低 = 好）、`max_dd_252`（回撤淺 = 好）、`beta_252`（\|beta\| 低 = 好） | beta 取絕對值（反向產品的負 beta 不是低風險） |
| 流動性 `liquidity` | `adv_usd_60`（高 = 好）、`amihud_60`（低 = 好） | log、log1p |
| 收益 `yield` | `trailing_yield_252`（高 = 好） | — |
| 存續期 `duration` | `rate_duration`（**僅債券 ETF**，方向隨 regime） | — |

**標準化（每個因子、每天、橫斷面）**：

1. 先依方向轉成「越高越好」。
2. Winsorize：截在當日橫斷面的第 5 與第 95 百分位，降低極端值影響。
3. z-score：同時計算「資產類別內」與「全體」兩種 z-score，各取 50% 混合。
   - 只用類別內：每個類別的第一名看起來一樣好，不管該類別整體是否在走強。
   - 只用全體：不同類別的分布差異（例如債券波動天生較低）會主宰結果。
   - 類別內有效樣本少於 5 檔時（例如波動率 ETP），只用全體 z-score。
4. 只用通過 §2 的標的計算分布，避免不可交易標的扭曲標準化。

缺值保持 NaN，**不填 0、不填中位數**。

## 4. 合成分數與 regime 權重

- 群組分數 = 該群組**可用**因子 z-score 的平均。
- 合成分數 `composite` = 可用群組的加權平均，權重依當日 regime，並在可用群組間**重新正規化**：

  `composite = Σ_g w_g · s_g / Σ_g |w_g|`（只加總有資料且適用的群組）

  因此缺資料的群組不會被當成「中性 0 分」，而是把它的權重讓給其他群組（降權）。
  `coverage` = 有資料的權重 / 適用的權重；低於 0.6 不排名。
- 每個因子的貢獻 `contribution_f = w_g / Σ|w| · z_f / n_g`，所有因子貢獻**加總恰好等於** `composite`
  （測試驗證），這就是 UI 的分數分解。

| 群組 | risk_on | neutral（含 unknown） | risk_off |
|---|---|---|---|
| momentum | 0.50 | 0.40 | 0.25 |
| low_risk | 0.20 | 0.30 | 0.45 |
| liquidity | 0.10 | 0.10 | 0.10 |
| yield | 0.10 | 0.15 | 0.10 |
| duration（僅債券） | −0.10 | 0 | +0.10 |

- 存續期是**有正負號的傾斜**：risk-off 偏好長天期（避險需求），risk-on 偏好短天期。
  這是常見但**不保證成立**的假設——2022 年股債同跌時長天期債並不避險。M4 以 ablation 檢驗。
- 權重是主觀設定、未對報酬做最佳化（降低過度擬合）；M4 做敏感度掃描。
- Regime 來自 ADR 0003 的規則式壓力分數；它的輸入（VIX、信用利差、曲線、美元、油價、黃金、
  GDELT 語調）是總體與「國際局勢」的**代理指標**，不是局勢本身的量測。

## 5. 風險懲罰

`score = composite − risk_penalty`，單位與 z-score 相同：

| 懲罰 | 預設 |
|---|---|
| 槓桿 | 0.25 × (\|槓桿\| − 1)，例如 3x 扣 0.5 |
| 反向（槓桿 < 0） | 0.25 |
| 波動率 ETP（VIX 期貨類） | 0.5 |
| 高波動 | 0.5 × (年化波動 / 40% − 1)，上限 1.0（40% 以下不扣） |
| 歷史不足一年 | 0.25 |

槓桿／反向與 VIX 類產品是每日重設或期貨展期的產品，長期持有有路徑耗損；除了扣分，
輸出的「主要風險」會加上持有期限警示。

## 6. Top 50 選取與約束

貪婪選取（可重現：同分以代碼排序）。每一步對剩餘候選計算

`adjusted_score = score − 0.04 × （同一資產類別/產業已入選檔數）`（**集中度懲罰**）

取最高且通過所有硬性約束者：

| 約束 | 預設 |
|---|---|
| 資產類別上限 | 個股 30、股票 ETF 20、債券 ETF 15、商品 ETF 10、貨幣 ETF 5、波動率 ETP 2 |
| 單一產業上限（資產類別/產業） | 8 |
| 槓桿／反向產品上限（`leverage != 1`，含 −1x） | 5 |
| 相關性去重 | 過去 126 個交易日日報酬相關係數 > 0.95 視為重複（例：SPY／VOO、HYG／JNK），只留分數高者 |

不符約束者記入 `skipped` 並附原因。若約束導致候選不足，輸出**少於 50 檔**，不會為了湊數放寬約束。

## 7. 可解釋性（輸出 JSON）

`data/rankings/top50-YYYY-MM-DD.json`（與 `latest.json`）每個入選標的包含：

- `score`（= composite − risk_penalty − concentration_penalty）、`composite`、各項懲罰、`coverage`
- `groups`：各群組分數、實際權重、貢獻
- `factors`：每個因子的原始值、z-score、貢獻
- `reasons`：**入選理由**＝貢獻最大的前三個正向因子
- `risks`：**主要風險**（最多 3 項，依嚴重度）：槓桿/反向（附持有期限警示）、波動率 ETP、高波動
  （> 40%）、深度回撤（< −30%）、高 \|beta\|（> 1.5）、利率敏感（債券存續期 > 10 年）、
  流動性偏低（成交額 < $20M）、歷史不足；都沒有時列出該資產類別的系統性風險

欄位定義見 [資料字典](data-dictionary.md#排名-datarankings)。

## 8. 已知限制

- **沒有財報型品質／價值因子**：免費來源沒有 point-in-time 財報（ADR 0003 §3）。個股的價值面只有
  配息率代理，因此排名偏向動能、低風險與高配息的特性。
- **商品／貨幣沒有期限結構因子**：只用動能與風險因子；商品 ETF 的展期成本未直接建模。
- **債券曲線位置**沒有獨立因子：曲線資訊只透過 regime 的 `curve` 成分間接影響權重。
- **權重、門檻、懲罰都是主觀設定**：可解釋，但未經最佳化；不同設定會給出不同排名。
- **相關性去重只看日報酬**：極短天期國庫券 ETF（BIL、SGOV）日報酬幾乎是雜訊，彼此相關性不高，
  可能同時入選。
- **存活者偏誤**：universe 是現有成分的靜態快照（ADR 0002）。
- **排名不是報酬預測**：回測方法見 [backtest.md](backtest.md)，結果見
  [backtest-report.md](backtest-report.md)（含與等權 universe、隨機基準的比較與偏誤揭露）。
