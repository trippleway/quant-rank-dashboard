# 回測方法

> **僅供研究與學習，不構成投資建議。** 回測是在明確假設下的歷史模擬，不是預期報酬。
> 最新結果見自動產生的 [`backtest-report.md`](backtest-report.md)；設計取捨見
> [ADR 0005](adr/0005-backtest-engine.md)。程式在 `src/qrd/backtest/`。

## 0. 執行

```bash
make features                   # 先有特徵
make backtest                   # = qrd backtest --report docs/backtest-report.md
.venv/bin/qrd backtest --sims 200 --no-robustness   # 快速版（不跑敏感度與 ablation）
.venv/bin/qrd backtest --start 2022-01-03 --end 2024-12-31   # 指定期間（不更新 latest.json）
```

## 1. 期間

- 預設最近 5 年（`--years`）。起點不得早於「至少 50 檔標的已有一年以上歷史」的第一天；
  若因此縮短，輸出 `period.shortened = true`，偏誤清單第一條會寫明實際期間。短於 1 年則拒絕執行。
- 前 3 年為樣本內、其餘為樣本外（不足時以 60% 切分）。**參數沒有用任何期間的回測結果調整**。

## 2. 時間對齊（無 look-ahead）

| 步驟 | 使用的資料 |
|---|---|
| 訊號日 t | 每週／每月第一個交易日（與前一交易日比較即可判定）；回測起點當天也是訊號日 |
| 排名 | `rank_asof(t)`：t 日因子快照（皆為 trailing）、t 日 regime（`available_date <= t` 的宏觀）、`date <= t` 的價量 |
| 成交 | t+1 收盤；新權重從 t+2 的報酬開始 |
| 成本 | 以 t 日（含）以前 60 日平均成交額分級 |
| 無風險利率 | 3 個月國庫券殖利率，前一交易日的值 |
| Regime 分析 | 每個交易日歸到「前一交易日收盤時」的 regime |

測試（`tests/test_backtest_lookahead.py`）：在兩個切點 C，把所有輸入截在 C（價格 `date <= C`、宏觀
`available_date <= C`）後**從特徵開始重跑**，持股、分數與每個組合（策略、SPY、60/40、等權）在 C 以前的
日報酬必須與完整歷史的結果相同（浮點誤差 1e-12 以內）；把 C 之後的價量與宏觀改成亂數也不得改變；
金絲雀（把 t+20 的因子標成 t）必須被偵測到。

## 3. 組合與成本

- **策略**：每次再平衡等權持有 Top N（預設 50；約束導致不足時持有實際檔數），期間權重隨價格漂移。
- **回測合格池**：與每日排名相同的過濾，另排除歷史不足一年者。
- **成本**（單邊，含佣金、價差與滑價）：ADV ≥ $100M 5 bps、≥ $20M 7.5 bps、其餘 10 bps；
  槓桿／反向／VIX ETP ×2。成本 = Σ |Δw| × bps，在成交日從組合價值扣除。
- **換手率**：每次 Σ|w_new − w_drifted| / 2（單邊），年化時不計首次建倉。

## 4. 基準

| 基準 | 定義 |
|---|---|
| SPY | 首次成交日買進持有 |
| 60/40 | 60% SPY + 40% AGG，每月再平衡 |
| 等權 universe | 每次再平衡等權持有所有回測合格標的（同頻率、同成本） |
| 隨機（運氣基準） | 1000 次；每次再平衡從合格池均勻抽出與策略相同檔數，等權、同成本、固定 seed。報告策略在隨機分布中的百分位 |

## 5. 指標

- 績效：CAGR、總報酬、年化波動、Sharpe（超額於無風險利率）、Sortino、最大回撤、Calmar、
  日勝率、**每期勝率**（各持有期報酬 > 0 的比例）、年化換手、年化成本拖累。
- 訊號品質：每期 IC（Pearson）與 Rank IC（Spearman），以訊號日所有合格標的的分數對下一個持有期報酬；
  平均、標準差、t 值、年化 IR、正值比例。十分位組合（等權、未扣成本）的每期與年化報酬、最高減最低。
- 各 regime 下的年化報酬、波動、Sharpe（策略與各基準）。
- 容量（量級參考）：每檔每次最多成交其 ADV 的 1% 時可容納的資金（各期取最小 ADV 檔），中位數與最差一期。

## 6. 穩健性

只在事前選定的**每月**頻率上執行（ADR 0005 §6）：

- 敏感度：Top 30、集中度懲罰 0／0.08、相關性門檻 0.90、只用全體／類別內 z-score、winsorize 1/99、
  風險懲罰 ×2、成本 ×0.5／×2。
- Ablation：固定 neutral 權重（無 regime）、逐一移除 momentum／low_risk／liquidity／yield／duration、
  移除風險懲罰。
- 每個變體列出全期 CAGR／Sharpe／MDD／換手與樣本內、樣本外 Sharpe；報告指出「樣本內最佳」變體的
  樣本外 Sharpe，示範挑參數的選擇偏誤。
- Deflated Sharpe：試驗數 = 基本設定 + 所有變體；DSR < 0.95 表示無法排除運氣。

## 7. 偏誤與限制

每份輸出（JSON `biases`、Markdown 報告）都附上：

- **存活者偏誤**：universe 是現有成分快照，會高估報酬。
- **資料品質**：yfinance／Yahoo 調整價可能有誤或事後修訂；回測用今天下載的調整歷史。
- **宏觀修訂**：FRED 非 vintage 資料。
- **成交假設**：t+1 收盤、固定 bps 成本；未模擬衝擊、無法成交、借券。
- **容量**：僅為量級參考。
- **多重檢定**：只計入列出的變體；隱性嘗試未計入。
- **參數未擬合**：樣本內／外切分不代表做過樣本內調參。
- **Regime 暖機**：早期 regime 成分較少（HY OAS 約 3 年、GDELT 約 3 個月歷史）。
